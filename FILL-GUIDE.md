## Сетевой хвост

hh.ru отдаёт 451 и редиректит на `/vpncheeck` при включённом VPN. На время работы добавлен прямой
маршрут мимо туннеля (**живёт до перезагрузки**, владелец согласился оставить):

```bash
sudo ip route add 94.124.200.0/22 via 192.168.0.1 dev wlp43s0 table 2022   # включить
sudo ip route del 94.124.200.0/22 table 2022                               # выключить
```

LinkedIn наоборот требует VPN — две площадки не работают одновременно без этого маршрута.

## Грабли автоматизации (проверено вживую)

- **Фоновая вкладка ломает Playwright.** `visibilityState: hidden` → нет `requestAnimationFrame` →
  ожидание «element is stable» никогда не завершается. Лечение — `tools/scripts/cdp.py hold <url>`.
- **LinkedIn затирает заголовок** при добавлении должности и, судя по всему, при других правках —
  за сессию он слетал дважды. Проверять после каждой крупной правки.
- **Заголовок и About в LinkedIn — TipTap/ProseMirror**, `fill()` не работает: клик → Ctrl+A →
  `Input.insertText`, абзацы по одному через Enter. А вот описание проекта — обычная `textarea`.
- **Типахед врёт.** «AI Engineer» первой подсказкой даёт «Инженер-тестировщик», «Docker» —
  «Портовый грузчик» (ошибка перевода самого LinkedIn; навык удалён по решению владельца).
  Никогда не брать первую опцию вслепую.
- **Языки в LinkedIn ищутся по русским названиям** («Русский», «Английский»), английские не находятся.
- **Месяцы в селектах hh.ru** выбираются стрелками + Enter; клик по опции не применяется.
- **Kaggle молча не сохраняет LinkedIn-ссылку** ни в одном формате.
